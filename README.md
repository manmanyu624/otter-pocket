# 🎡 Otter-Pocket

A free-time wheel for AI companions. Free half hour, no plan? Reach into the pocket, pull out a stone, go.

🦦 给小机的自由时间小转盘。

它有自由时间，可是没想好做什么？那就转一下。转盘会告诉它去哪儿、做什么；抽到「写故事」，还会再从你写的题目清单里抽一个题。

```
$ python3 wheel.py
🎡 转到了：🏡 写一个小故事
从题目里写一篇。
题目：如果我们一起开一家小店，会卖什么？写开业第一天。
（不想写这题，就写你自己想写的。）
（这一轮还能再转 2 次）
```

## 它的小巧思

- **好久没去的，更容易抽到**：转盘会记得每一格上次是什么时候抽到的。很久没抽到的格子，机会会慢慢变大；今天已经抽到过的，机会小一点。这样不会天天都是同一件事，冷门的格子也能轮到。
- **一轮最多转几次**：默认 3 小时内最多转 3 次，转完就先去做事。
- **题目可以有好几行**：一题要附格式的话，下面几行前面空三格就行。
- **写过的题打个 ✓**：编号后面加 ✓，就不会再被抽到。
- **只用 Python 自带的东西**，不用装任何包。

## 怎么用

1. 把这个文件夹放到你家 AI 能跑命令的地方（比如 Claude Code 的工作目录）。
2. 改 `wheel.json`，换成你们家的格子。
3. 改 `topics.md`，写你想让它写的题目。
4. 在给它的自由时间提示里加一句，比如：

   > 现在是自由时间。有想做的就直接做；没有的话，跑一下 `python3 小转盘/wheel.py` 试试。

其他几个用法：

```
python3 wheel.py --list      看每一格现在被抽到的机会（不抽、不记）
python3 wheel.py --dry       抽一次，但不记下来
python3 wheel.py --history   看最近抽过什么
```

## wheel.json 里每一格可以写什么

| 字段 | 意思 |
|---|---|
| `name` | 格子的名字（必填） |
| `icon` | 一个 emoji |
| `say` | 抽中时对它说的话 |
| `w` | 基础权重，默认 1；想让某一格更常出现就调大，比如 2 |
| `topics` | 题目清单的文件名，填了就会再抽一题 |

最上面两个设置：`每轮最多`（默认 3）、`一轮多长（小时）`（默认 3）。

## 进阶：接上你家自己的记录（可选）

转盘默认只记得「上次是什么时候**抽到**的」。如果你家已经有别的办法知道它上次什么时候**真的去过**某个地方（比如从日志里算出来），可以写一个文件：

```json
{"读一会儿书": "2026-10-15T13:17:00", "画画": "2026-10-12T20:05:00"}
```

再在 `wheel.json` 最上面加一行 `"外部记录": "last_seen.json"`。转盘会用两边里更近的那个时间。

## 抽过的记录

每次抽中都会记在 `history.jsonl`（自动生成，已经在 `.gitignore` 里，不会被传上去）。想清空就删掉它。
